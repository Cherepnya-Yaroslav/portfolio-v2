# Портфолио Ярослава

Двуязычное портфолио frontend/fullstack-разработчика: Next.js App Router, React, TypeScript и Tailwind CSS. `/` перенаправляет на `/ru`. Без Supabase `/ru` и `/en` — статическая демоверсия; после подключения страницы получают опубликованные проекты из базы при запросе.

## Админка

`/admin` — вход через Supabase Auth, создание и редактирование проектов, RU/EN, загрузка обложек, черновики, публикация, порядок, фильтры и удаление. Изменения на сайте не требуют пересборки. Доступ к данным ограничивается RLS и списком назначенных администраторов.

Для реальной работы нужен новый проект Supabase: [инструкция подключения](docs/admin-setup.md). В коде нет рабочих ключей, паролей или обхода авторизации. До подключения `/admin` показывает шаги настройки.

## Локальный запуск

Требуется Node.js 22+.

```sh
npm install
npm run dev -- --port 3001
```

Откройте [русскую версию](http://localhost:3001/ru) или [английскую версию](http://localhost:3001/en). Порт 3001 выбран, чтобы не конфликтовать с другими проектами на стандартном порту 3000.

Production-режим:

```sh
npm run build
npm run start -- --port 3001
```

## Изменение материалов

Проекты после подключения Supabase редактируются через `/admin`. Остальной контент и демопримеры находятся в `src/content/portfolio.ts`:

- `profile`: имя, путь к портрету и технологии.
- `copy.ru` / `copy.en`: тексты, навигация, подписи и metadata.
- `projects`: демопримеры, используемые только пока Supabase не настроен. Реальные карточки, видимость, порядок и признак концепта изменяются через админку.
- `contacts`: добавьте `href` и `value`. Email использует `mailto:`, Telegram и GitHub — полный HTTPS-адрес. Без адреса контакт остаётся явно подписанной заглушкой.

Примеры работ — вымышленные концепты, а не утверждения о реальном опыте. Технологии и описание специализации предварительные. Перед публикацией замените контент и удалите соответствующие демоподписи, обновите год, если необходимо. Количество работ в заголовке определяется автоматически.

Превью лежат в `public/projects` в формате SVG; их можно заменить собственными изображениями. Портрет находится в `public/images/yaroslav.webp`, исходные PNG сохранены в `images`. Manrope поставляется локально через Fontsource; запросов к Google Fonts нет.

## Поведение

- RU / EN сохраняет видимый раздел страницы.
- Карусель: стрелки, нативный свайп/прокрутка, клавиши ← / → / Home / End при фокусе на ленте. Без автоперелистывания и зацикливания.
- Появление секций и лёгкий параллакс отключаются при `prefers-reduced-motion`; параллакс доступен только с точным указателем на широком экране.
- Контент доступен без JavaScript; карусель остаётся прокручиваемой, переключение языков работает обычными ссылками.

## Проверки

```sh
npm run lint
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:admin
npm run test:db
```

`test:e2e` запускает production-сервер на порту 3100. Проверяет оба языка на ширинах 360, 390, 768, 1440 и 1920 px, переходы, metadata, клавиатуру, свайп, изменение размера карусели, уменьшенное движение и валидацию проектов. Базовые тесты демоверсии выполняются без настроек Supabase.

`test:admin` использует отдельный dev-сервер на 3101 и тестовый HTTP-сервер Supabase на 3111; `test:db` проверяет настоящую миграцию и RLS во временном PostgreSQL в Docker. Скриншоты сохраняются в `test-results`. Тесты не подключаются к облачной базе.

Публикация и домен не настроены. Перед публикацией задайте `metadataBase` с реальным доменом в `generateMetadata` и проверьте canonical / языковые альтернативы на нём. Сервер сообщений не используется; база и хранение обложек для админки предоставляются Supabase.
